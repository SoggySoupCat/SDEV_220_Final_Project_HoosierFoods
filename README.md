# Hoosier Hills Food Bank - Inventory Management System

## 1. Project Description
**Client Name:** Hoosier Hills Food Bank  
**System Purpose:** An automated inventory management and distribution tracking desktop application designed to streamline daily stock management and donor tracking.

### Scope & Features
* **GUI:** A `tkinter`-based interface for navigation, stock entry, and reporting.
* **Core Classes:**
  * **Item:** Manages item names, quantity, expiration dates, and categories.
  * **Donor:** Manages donor contact details and donation histories.
  * **Transaction:** Handles incoming donations and outgoing distributions.
* **Data Structures:** Uses Python dictionaries to look up inventory items by ID and lists to track overall activity histories.
